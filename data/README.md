# Data

## Source
GA4-style e-commerce behavioral events — Kaggle cosmetics-shop dataset.
~20.7M rows across 5 months (Oct 2019 – Feb 2020).

## Structure

| Folder | Contents | In Git? |
|--------|----------|---------|
| `raw/` | Original monthly CSVs (~2.4 GB) | No — excluded via `.gitignore` |
| `cleaned/` | Processed outputs | No — regenerated from source |
| `powerbi/` | Aggregated extracts for the dashboard | No — regenerated by export script |

## Schema (raw events)
`event_time` · `event_type` · `product_id` · `category_id` · `category_code` ·
`brand` · `price` · `user_id` · `user_session`

> Raw files are excluded to respect GitHub size limits. Run `notebooks/01_load_data.py`
> to rebuild the database from the source CSVs.
