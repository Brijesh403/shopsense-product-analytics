# Power BI Dashboard

A 4-page executive dashboard translating the SQL findings into a stakeholder-ready
report.

## Pages

| Page | Focus |
|------|-------|
| Executive Overview | Headline KPIs, monthly revenue, and ARPU trend |
| Funnel Analysis | Conversion funnel, stage drop-offs, cart-abandonment gauge |
| Cohort Retention | Monthly retention heatmap and decay curves |
| User Segmentation | RFM segments and revenue contribution by segment |

## Files
- `Shopsense_Product_Analysis.pbix` — the editable report
- `screenshots/` — exported PNGs of every dashboard page and EDA chart

> Built on aggregated extracts rather than the raw 20.7M-row table for performance.
